Python reference

Lists

  • Index from 0; a[-1] last. a[s:e:k] stops before e; leave parts out for start/end. a[::-1] reversed, a[::-2] every 2nd from the end.
  • range(s, e, k) stops before e: range(2, 10, 3) → 2, 5, 8. To include n: range(…, n + 1).
  • append(x) end · insert(i, x) · remove(x) first match · pop(i) · x in a · len(a) · sorted(a) new sorted list
  • b = a is the same list (alias). Copy: a.copy() or a[:]. Same for dicts: d.copy().
  • for i, v in enumerate(a) → index and value.

Operators

  • % remainder (x % 2 == 0 even; x % 2 is 1 = truthy for odd) · ** power · / always gives a float · // whole-number division
  • == != < <= · and both · or at least one · "more than" is >, "at least" is >=

Dicts and sets

  • d[k] = v adds or overwrites · d[k] += v needs k to exist · d[k] on a missing key → KeyError · d.get(k, 0) → 0 instead
  • for k in d → keys · d.values() · d.items() → (key, value) · k in d checks keys
  • {day: [] for day in days} gives each key its own empty list
  • max(d, key=d.get) → key with the biggest value (key= says "compare by this")
  • set(lst) drops duplicates (and order) · | union · & intersection · - difference

def remove_dups(lst):           # 1a A [10]
    result = []
    for item in lst:
        if item not in result:
            result.append(item)
    return result      # AFTER the loop

def count_dups(lst):            # 1a B [6]
    unique_list = remove_dups(lst)
    return len(lst) - len(unique_list)
def is_fib(seq):                # 1b A [8]
    if len(seq) < 2:
        return False
    if seq[0] != 0 or seq[1] != 1:
        return False
    for i in range(2, len(seq)):  # look back 2
        if seq[i] != seq[i-1] + seq[i-2]:
            return False          # fail fast
    return True       # only after the loop

def fib(n):                     # 1b B [8]
    fib_seq = [0, 1]
    if n == 0:
        return fib_seq[0:1]       # [0]
    if n == 1:
        return fib_seq
    for i in range(2, n + 1):     # length n+1
        fib_seq.append(fib_seq[i-1] + fib_seq[i-2])
    return fib_seq

  • True/False functions: return False inside the loop the moment something fails; return True after the loop.

Q3 · Histograms ~5–6 pts · Easy

  1. Count per bin. [a,b) includes a, not b, so an edge value goes to the right bin. The last bin is closed ([20,30] includes 30).
  2. Probability (relative frequency) = count ÷ n. Bars sum to 1.
  3. Density = probability ÷ bin width. Area sums to 1: check width × Σ heights = 1.
  • Mass histogram (discrete counts): one bar per value, height = trials with that value ÷ total trials. No width.
  • Number of bins: √n, or Sturges ⌈log₂ n⌉ + 1 (n = 64 → 7). Too many bins → few points each → noisy, spiky. Too few → hides the shape.
  • plt.hist(data, density=True) draws the density version.

1a: [12, 3, 30, 6, 8, 1, 15, 12, 9, 4], bins [0,10) [10,20) [20,30] → counts 6, 3, 1 → 0.6, 0.3, 0.1 → ÷10 → 0.06, 0.03, 0.01.
1b: 1, 3, 11, 5 of 20 trials → 0.05, 0.15, 0.55, 0.25.
Lab: 21 of 100 days, width 5 → 0.21 → 0.042.

Q3 · Distributions ~10 pts · Easy

  • f(x) (PDF) = height of the curve, not a probability; P(X = one exact value) = 0 for continuous X.
  • F(x) = P(X ≤ x) (CDF) = area up to x. "at most" → F(x) · "more than" → 1 − F(x) · "between a and b" → F(b) − F(a).
  • Bernoulli(p): one yes/no trial. p̂ = successes ÷ trials (20 of 200 → 0.1).
  • Binomial(n, p): P(X=k) = C(n,k)·pk(1−p)n−k; mean np; variance np(1−p); SD √(np(1−p)).
  • At least (discrete): add the PMF values. P(X ≥ 9) of 10 = P(9) + P(10).
  • Estimate p from a count table: x̄ = Σ(value × trials) ÷ total trials, then p = x̄ ÷ n.
  • Exponential(λ): f = λe−λx, F = 1 − e−λx, P(X > x) = e−λx, mean 1/λ.
  • Normal N(μ, σ²): the second number is the variance (N(50, 5²): SD 5). Use 68–95–99.7.

1a (λ = 0.1): P(X ≤ 10) = F(10) = 1 − e−1 = 0.632. P(X > 20) = 1 − F(20) = e−2 = 0.135.

1b: x̄ = (7·1 + 8·3 + 9·11 + 10·5)/20 = 180/20 = 9 → p = 9/10 = 0.9.
P(9) = C(10,9)(0.9)9(0.1) = 10(0.39)(0.1) = 0.39. P(10) = (0.9)10 = 0.35. P(X ≥ 9) = 0.74: "74% chance at least 9 of 10 packets get through."

Lab: Bin(4, 0.5): P(2) = 6/16 = 0.375 · Exp(λ=2): P(X > 0.5) = e−1 = 0.368.

Trap using F(x) for "more than" · forgetting the C(n,k) factor · a mass histogram isn't divided by a width.

Q4 · CLT 16–18 pts · Easy

  1. Population: μ = np, σ = √(np(1−p)) if it's Binomial (else they're given).
  2. Sampling distribution: x̄ ≈ Normal(μ, σ²/n): mean μ, SE = σ/√n, Var(x̄) = σ²/n. Say "approximately normal by the CLT".
  3. P(x̄ > c): z = (c − μ)/SE, then the one-tail table (z = 1 → 0.16, 2 → 0.025, 3 → 0.0015). P(x̄ < c) for c above μ = 1 − tail.
  4. n for a target SE: SE = σ/√n → n = (σ/SE)². 4× n → ½ SE.
  • The population shape does not matter (skewed, discrete, unknown); n ≥ 30 rule of thumb. That's the point of the CLT.
  • Parameters (μ, σ) describe the population; statistics (x̄, s) the sample. Sample variance s² divides by n − 1. If σ is unknown, use s.
  • X̄ (capital) and x̄ are the same sample mean.

1a: Bin(100, 0.8): μ = 80, σ = √16 = 4; n = 64 → mean 80, SE = 4/8 = 0.5. P(x̄ > 81): z = 1/0.5 = 2 → 0.025. SE = 0.25: √n = 4/0.25 = 16 → n = 256.
1b: μ = 10, σ = 4, n = 64 → N(10, 0.5²). P(x̄ > 10.5): z = 1 → 0.16.
Lab: Bin(50, 0.2): μ = 10, σ² = 8; n = 100 → Var(x̄) = 0.08. 400 days → SD of x̄ halves.

Trap σ instead of σ/√n for a question about the mean · Var(x̄) = σ²/n has no square root · forgetting to say "Normal".

Q5 · Hypothesis test 16–18 pts · Medium

  1. Hypotheses: H₀: μ = μ₀ (two samples: μA = μB, i.e. μA − μB = 0). H₁: μ ≠ μ₀ for "differs". Always μ, never x̄. H₀ is "no difference"; the claim goes in H₁.
  2. Test statistic: z = (x̄ − μ₀)/(σ/√n). Name each value: x̄ = …, μ₀ = …, σ = …, n = ….
    Two samples: SE = √(σA²/nA + σB²/nB), z = (x̄A − x̄B)/SE.
  3. Tails, and say why: "differs" / ≠ → two-tailed (either direction counts). "greater", "increased", "less" → one-tailed.
    Two-tailed p = 2·P(Z > |z|): |z| = 1 → 0.32, 2 → 0.05, 3 → 0.003. One-tailed: halve it.
  4. Decide: p < α → reject H₀; otherwise fail to reject H₀. Never "accept". Or use critical values: two-tailed, reject if |z| > 2 (α = 0.05) or |z| > 2.5 (α = 0.01).
  5. Conclude in context (a sentence about the real quantity).
  • p-value = probability of data at least this extreme if H₀ were true. α = the cutoff you're given (0.05, 0.01).
  • Same p, different α: p = 0.023 → reject at 0.05 and 0.1, not at 0.01.
  • Why not "accept H₀"? Not finding evidence against H₀ doesn't prove it; the sample may be too small to see a difference.
  • t-test: σ unknown and n < 30 → use s and the t-distribution with n − 1 degrees of freedom (fatter tails).

1a: SE = √(100/50 + 100/50) = √4 = 2; z = (46 − 40)/2 = 3; |3| > 2 (p ≈ 0.003 < 0.05) → reject H₀.
1b: z = (253 − 250)/(6/√36) = 3/1 = 3; two-tailed (H₁: μ ≠ 250); p = 2(0.0015) = 0.003 < 0.01 → reject.
Lab: SE = 22/10 = 2.2, z = −5/2.2 = −2.27 · two lines: SE = √2 ≈ 1.41, z = 3/1.41 = 2.12 > 2 → reject.

Trap x̄ in H₀ · not doubling the tail for two-sided · "accept" · no sentence in context.

Q6 · Confidence interval 16 pts · Medium

  1. SE = s/√n (σ/√n if σ is known).
  2. Write the formula, then: x̄ ± z·SE with the exam's z (90% 1.5, 95% 2, 99% 2.5).
  3. Give [lower, upper].
  • Margin = z·SE · width = 2·z·SE.
  • More data → smaller SE → narrower (4× n → half the width). More confidence → wider. More spread (s) → wider.
  • Meaning: if we repeated the sampling many times, about 95% of the intervals would contain μ. μ is fixed; the interval is what's random. Not "95% chance μ is in this interval", not "95% of the data".
  • One-sided bound: use the one-sided z; the other end is ±∞.
  • Small n, σ unknown: use t with n − 1 df instead of z (wider).
  • Picture question (new sample, 4× n): μ stays put; width about half; a new x̄, likely closer to μ; most likely contains μ. Rule out any option that moves μ, is wider, or keeps the old x̄.

1a: SE = 24/√64 = 3; 90%: 57 ± 1.5(3) = 57 ± 4.5 = [52.5, 61.5]. With 400 students SE = 24/20 = 1.2 → "SE smaller, CI narrower" (B).
1b: SE = 1.5/√900 = 0.05; 99%: 7.2 ± 2.5(0.05) = 7.2 ± 0.125 = [7.075, 7.325]. Picture: D.
Lab: 95 ± 2(2.2) = (90.6, 99.4).

Trap forgetting √n · using the one-sided z for a two-sided interval · saying μ moves.

Q7–8 · Regression most points: 46 · Medium

Write X, y and the equation (don't solve)

  • One row per data point. Columns = features in the same order as β, then a column of 1s for b.
  • A squared feature is just another column: x₁ = 40, 50, 60 → x₁² = 1600, 2500, 3600. Still "linear" regression (linear in β).
  • Write XᵀXβ = Xᵀy (or β = (XᵀX)⁻¹Xᵀy). Xᵀ = X with rows and columns swapped.
1a:     [ 500  100  1 ]        [14]
    X = [ 800  200  1 ]    y = [10]   XᵀXβ = Xᵀy
        [1000   50  1 ]        [11]
        [ 600  300  1 ]        [ 9]
1b (β = [a1, a2, a3, b], model a1·x1 + a2·x1² + a3·x2 + b):
        [40  1600  1500  1]        [800]
    X = [50  2500  2000  1]    y = [900]
        [60  3600  2500  1]        [950]

Dimensions and "no unique solution"

  • X is n × (features + 1); XᵀX is (features + 1) × (features + 1). 50 points, 3 features → 50×4 and 4×4.
  • More unknowns than data points (1a: 3 points, 4 features + b = 5 unknowns → X 3×5, XᵀX 5×5): the columns are linearly dependent, so XᵀX is not invertible and infinitely many β fit perfectly.
  • Same thing if one feature is a multiple of another (x₃ = 2x₁). Ridge (+λI) makes it invertible again.

Predict, MSE, R²

  • ŷ = a₁x₁ + a₂x₂ + b. Residual = y − ŷ.
  • MSE = Σ(y − ŷ)² ÷ number of points.
  • R² = 1 − MSE/σy² = fraction of the variance explained. Near 1 is good (0.8 → "explains 80%"), near 0 is bad (0.12 → "only 12%, not a good model").
  • One point with a huge residual: an outlier, something the features don't capture, or a recording error.
  • Comparing weights is only fair after standardizing each feature, (x − x̄)/s. Otherwise the scale decides the size.
  • One feature by hand: a = (Σxy − n·x̄·ȳ)/(Σx² − n·x̄²), b = ȳ − a·x̄. (1,2), (2,3), (3,5) → a = 1.5, b = 0.333.

1a: ŷ₅ = −0.01(700) − 0.02(150) + 21 = −7 − 3 + 21 = 11; ŷ₆ = −9 − 5 + 21 = 7; MSE = (1.5² + 1.5²)/2 = 2.25. R² = 1 − 0.8/4 = 0.8, good fit.
1b: ŷ = 20+16+30 = 66, 40+18+30 = 88, 32+14+30 = 76; residuals 10, −8, −10 → MSE = (100+64+100)/3 = 88. R² = 1 − 88/100 = 0.12, not good.

Trap forgetting the 1s column · columns not in β order · MSE ÷ the wrong count · writing 1 − σ²/MSE.

Q8 · Ridge & cross-validation ~10 pts · Hard

  • Ridge: minimize ‖y − Xβ‖² + λ‖β‖²; β = (XᵀX + λI)⁻¹Xᵀy. ‖β‖² = sum of squared entries.
  • Penalty value = λ(a₁² + a₂² + …). Leave out b unless the question says the penalty is on the full vector (1a did).
  • Bigger λ → smaller weights, smoother model. λ = 0 is plain least squares. One feature, no intercept: a = Σxy/(Σx² + λ).
  • Among several perfect fits, ridge picks the smallest ‖β‖². Ridge mitigates overfitting.
  • Scale bias: a feature with small numbers (x₁ 30–70 vs x₁² 900–4900 and x₂ 1000–3000) needs a big weight, so ridge over-penalizes it. Fix: standardize features first.
  • Overfitting: low training error, high test error (too many parameters; fix: raise λ, simpler model). Underfitting: high error on both.
  • Train/test split (80/20 or 90/10). The test set stays untouched during training and tuning; use it once at the end for an unbiased error. A validation set is held back from training to compare λ values.
  • k-fold CV: split into k folds; train on k − 1, validate on the 1 left out; repeat k times; average the validation MSE. To pick λ: k models per λ (4 λ values × 5 folds = 20 models), take the best λ, refit once on all the training data. LOOCV: k = n.
  • Trade-off: k-fold gives a more stable estimate (every point is validated once), but trains the model k times.

1a: ‖β₁‖² = 2² + 3² = 13, ‖β₂‖² = 1+1+1+1+4 = 8 → ridge picks β₂, mitigates overfitting. CV trade-off: B. Test set: C (untouched, final estimate only).
1b: penalty = 2(6² + 0.8² + 0.6²) = 2(36 + 0.64 + 0.36) = 74 (b not penalized). Fairness: (b), a₁ over-penalized because x₁ is on a small scale.

Trap tuning on the test set · penalizing b when not asked · forgetting to square · thinking a big weight means an important feature.

Full-credit wording copy these

CLT distribution:

By the CLT, x̄ is approximately Normal with mean μ = 80 and SE = σ/√n = 4/√64 = 0.5.

Hypotheses:

H₀: μ = 250 (the machine is calibrated). H₁: μ ≠ 250.

Tails:

Two-tailed, because H₁ is μ ≠ 250: a difference in either direction counts.

Decision:

p = 0.003 < α = 0.01, so we reject H₀: strong evidence that the mean fill differs from 250 mL.

p = 0.03 > α = 0.01, so we fail to reject H₀: not enough evidence that the mean differs.

CI meaning:

If we repeated the sampling many times, about 90% of the intervals built this way would contain the true mean μ.

More data:

SE = s/√n decreases as n grows (from 3 to 1.2), so the interval becomes narrower.

Least squares setup:

X has one row per data point and a final column of 1s for the intercept; the normal equation is XᵀXβ = Xᵀy.

No unique solution:

X is 3×5, so XᵀX is 5×5 but has rank at most 3. With more unknowns (5) than data points (3) the columns are linearly dependent, XᵀX is not invertible, and infinitely many β fit the data.

R²:

R² = 1 − 88/100 = 0.12: the model explains only 12% of the variance in satisfaction, so it is not a good fit.

Large residual:

Last-minute checklist

  • Every return that ends a search sits after the loop.
  • Every range end: does it need + 1?
  • list(…) around every map/filter; reduce imported.
  • Dict loops use .items() when you need values.
  • Questions about a mean use SE = σ/√n.
  • Two-sided p-values doubled; "fail to reject", never "accept".
  • Hypotheses use μ, not x̄.
  • Density divided by the bin width; the last bin includes its right edge.
  • X has the 1s column, and its columns follow β's order.
  • MSE divides by the number of points; R² = 1 − MSE/variance.
  • Ridge penalty skips b unless told otherwise.
