Start here

A plain-language refresher for each topic, something to play with, then warm-ups that build up to exam shape.

  1. Read the refresher. The few ideas each topic really tests, plus the traps.
  2. Do the warm-ups. In code warm-ups, replace every ____ with your code and press Run tests; number answers take decimals (0.25) or fractions (1/4). Each set opens with what the exam asks on that topic, then builds it one piece at a time. The last warm-up is an exam-style question with new numbers. Numbers are checked instantly; code runs real Python in your browser.
